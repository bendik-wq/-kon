## Utgift – kostnad – utbetaling
| Begrep | Når? | Eksempel |
|--------|------|----------|
| **Utgift** | Når vi pådrar oss forpliktelsen (mottar varen/fakturaen) | Kjøper maskin på kreditt |
| **Kostnad** | Når ressursen forbrukes (periodiseres) | Avskrivning på maskinen hvert år |
| **Utbetaling** | Når pengene forlater bedriften | Betaler fakturaen |

Tilsvarende på inntektssiden: **inntekt** (opptjent/levert) – **innbetaling** (penger mottatt).

## Gruppering av kostnader
- **Etter art:** varekostnad, lønn, avskrivninger, andre driftskostnader
- **Etter variabilitet:** faste (uavhengig av aktivitet) vs. variable (endres med aktivitet)
- **Etter henførbarhet:** direkte (kan knyttes til produkt) vs. indirekte (felleskostnader)
- **Etter funksjon:** tilvirkning, salg, administrasjon

## Materialkostnad / varekostnad
```
Varekostnad = IB varelager + varekjøp − UB varelager
Varekostnad = varekjøp ± beholdningsendring
```

## Lønnskostnader
```
Lønnskostnad = brutto lønn + feriepenger + arbeidsgiveravgift (+ OTP o.l.)
Feriepenger  ≈ 10,2 % (12 % ved 5 uker ferie i avtale) av feriepengegrunnlaget
AGA          = sats (sone I: 14,1 %) × (lønn + feriepenger)
```

## Avskrivninger
```
Lineær:        årlig avskrivning = (anskaffelseskost − restverdi) / levetid
Saldo:         årlig avskrivning = saldo (bokført) per 1.1 × saldosats
Bokført verdi = anskaffelseskost − påløpte avskrivninger og nedskrivninger
```

## Merverdiavgift (MVA)
- Satser: 25 % (generell), 15 % (næringsmidler), 12 % (persontransport, overnatting m.m.)
- Inngående MVA (innkjøp) trekkes fra utgående MVA (salg); differansen betales til staten
- MVA er ikke en kostnad/inntekt for en MVA-registrert bedrift
```
Pris inkl. MVA = pris ekskl. × (1 + sats)
MVA-andel av pris inkl. = sats / (1 + sats)   (25 % → 20 %)
```
