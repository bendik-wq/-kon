## Læringsmål
- Forstå hva bedriftsøkonomi er og hvilke beslutninger faget støtter
- Kjenne bedriftens oppgaver, interessenter og samfunnsansvar
- Forstå økonomistyring: planlegging → gjennomføring → kontroll
- Kjenne selskapsformer og hva som kreves for å etablere en virksomhet
- Reflektere over etikk og bruk av KI i bedriftsøkonomisk analyse

## Nøkkelbegreper
| Begrep | Forklaring |
|--------|-----------|
| Bedriftsøkonomi | Fag om hvordan bedrifter tar økonomiske beslutninger |
| Interessenter | Eiere, ansatte, kunder, leverandører, långivere, stat/samfunn |
| Økonomistyring | Planlegging, gjennomføring og kontroll av økonomiske mål |
| Finansregnskap | Eksternt regnskap etter lov og standarder (resultat, balanse) |
| Driftsregnskap / internregnskap | Internt beslutningsgrunnlag (kalkyler, budsjett) |
| ENK | Enkeltpersonforetak – eier har personlig, ubegrenset ansvar |
| AS | Aksjeselskap – begrenset ansvar, min. aksjekapital 30 000 kr |
| ANS / DA | Ansvarlig selskap – solidarisk resp. delt ansvar |
| Samfunnsansvar (CSR) | Ansvar utover lov: miljø, ansatte, lokalsamfunn |
